# NotebookLM 2.0으로 나만의 AI 지식비서 만들기 — 강의 랜딩페이지

**강사**: 이연희 강사
**강의 형식**: 오프라인 실습형 · 90분
**대상**: 일반 성인 초보자 (ChatGPT는 써봤지만 NotebookLM은 처음인 분)

---

## 1. 콘셉트 요약

ChatGPT에는 익숙하지만 NotebookLM은 낯선 성인 학습자를 대상으로, "출처가 있는 답변, 믿을 수 있는 나만의 AI 지식비서"라는 한 문장 차별점을 중심에 두고 90분 안에 소스 등록 → 콘텐츠 생성까지 직접 경험시키는 실습형 강의입니다. 랜딩페이지는 강의 소개 자료이자 실제 수업 진행용 슬라이드 자료로 동시에 쓸 수 있도록, 클레이모피즘(Claymorphism) 스타일의 10페이지 스크롤형 단일 HTML 문서로 제작했습니다.

## 2. 10페이지 구성표

| # | 페이지 | 핵심 메시지 |
|---|--------|-------------|
| 1 | 표지 | 90분이면 충분하다는 확신 전달 |
| 2 | 왜 이 도구인가 | 출처 기반 답변이라는 유일 차별점 |
| 3 | 오늘 배울 내용 | 90분 타임테이블로 전체 흐름 예고 |
| 4 | 시작하기 | 접속~화면 이해 4단계 |
| 5 | 실습① 소스 넣기 | PDF·유튜브·웹사이트·음성 등록 |
| 6 | 실습② 콘텐츠 생성 | 오디오 요약·슬라이드·마인드맵·쇼츠 |
| 7 | 기능 한눈에 보기 | 전체 기능 지도 인포그래픽 |
| 8 | 활용 시나리오 & 링크 | 실생활 적용 사례 + 신청/문의 CTA |
| 9 | 활용 사례 & 요약 | 핵심 4가지 리마인드 |
| 10 | 마무리 / CTA / Q&A | 신청 유도 + 질의응답 |

각 페이지의 상세 기획(핵심 메시지·카피·이미지·CTA·레이아웃·발표자 메모)은 `slides/slide-01.md` ~ `slide-10.md`에 정리되어 있습니다.

## 3. 디자인 가이드

**콘셉트**: 클레이모피즘 — 찰흙처럼 말랑말랑한 3D 질감, 둥근 모서리, 이중 박스섀도우로 볼록한 입체감 표현

**컬러 팔레트**
| 이름 | 값 | 용도 |
|------|-----|------|
| 라벤더 | `#E9DEFB` | 배경 그라데이션 |
| 민트 | `#CFF6E4` | 배경 그라데이션 |
| 피치 | `#FFE3D3` | 보조 배경 |
| 스카이 | `#D9EEFF` | 기본 배경 |
| 옐로우 | `#FFF2BE` | 보조 배경 |
| 퍼플(주 강조) | `#8B6EF2` | 헤드라인 강조, 버튼, 아이콘 |
| 코랄(CTA 강조) | `#FF8A65` | CTA 버튼 |

**타이포그래피**: Noto Sans KR, 본문 18px 이상, `word-break: keep-all`로 한글 단어 중간 줄바꿈 방지

**카드 스타일**: `border-radius: 24~32px` + 이중 박스섀도우(`--shadow-raised`, `--shadow-pressed`)로 양각/음각 플라스틱 질감 구현

**버튼 스타일**: pill 형태(`border-radius: 999px`) + 그라데이션, hover 시 위로 떠오르고 클릭 시 눌리는 피드백(`--shadow-pressed`)

**여백/가독성**: 슬라이드당 메시지 1~2개만 강조, 모바일에서는 2단 레이아웃이 1단으로 전환(`@media max-width: 860px`)

## 4. 폴더 구조

```
notebooklm2-lecture-landing/
├── index.html          # 10슬라이드가 모두 담긴 랜딩페이지 본체 (스크롤 이동)
├── style.css           # 클레이모피즘 디자인 시스템
├── script.js           # 점 네비게이션(현재 슬라이드 표시) 스크립트
├── assets/
│   ├── images/         # 실제 사용된 인포그래픽 4장 + 추가 스크린샷 자리
│   └── icons/          # (필요 시 커스텀 아이콘 추가)
├── slides/
│   └── slide-01.md ~ slide-10.md   # 페이지별 기획안 + 카피 + 발표자 메모
├── README.md            # 본 문서
└── NOTES.md              # 이미지 교체·링크 연결 등 제작 유의사항
```

## 5. 제작 시 유의사항

1. **CTA 링크 미확정**: 신청폼·카카오톡 채널·강의 예고 영상 링크가 아직 없어 `index.html`의 해당 `<a href="#">`를 placeholder로 두었습니다. 링크가 확정되면 `NOTES.md`의 표를 참고해 교체하세요.
2. **스크린샷 자리표시자**: 4번(시작하기), 5번(실습①), 6번(실습②) 슬라이드에 점선 테두리의 `[이미지 삽입 위치: ...]` placeholder가 있습니다. 실제 강의 화면 캡처본을 받으면 `<img>` 태그로 교체하세요. 끝까지 준비되지 않으면 삭제 후 레이아웃을 1단으로 자연스럽게 조정하면 됩니다.
3. **이미지 최적화**: 원본 카카오톡 캡처 이미지(4~5MB)는 웹 로딩 속도를 위해 1600px 이내로 리사이즈하고 JPG 품질 82로 압축해 `assets/images/`에 반영했습니다(68KB~308KB 수준).
4. **배포**: 정적 HTML/CSS/JS만으로 구성되어 있어 GitHub → Vercel로 바로 배포 가능합니다(빌드 설정 불필요).
